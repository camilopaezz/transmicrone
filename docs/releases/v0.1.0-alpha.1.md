First Android prerelease for personal TransMilenio and SITP arrivals boards.

- Save stations or stops, select services, and switch between boards.
- Search services and places, inspect route directions and ordered stops.
- Display vehicle reports with source freshness, retry failures, and retain saved boards.

Validation: 90 unit tests, 35 Android 16 emulator tests, and five Python tests passed. Android lint reported zero errors and 13 warnings.

Known limitations:
- The unofficial live feed can reject requests. The latest emulator check received server rejections, so current arrivals were not confirmed in that check.
- The FZ63 composite selection is mapped to the verified Z63/Tibanica direction on route 13789. Other composite mappings remain unsupported until verified.
- Android 8.0 or later is required.

This APK is a live-data release build signed with the permanent release key. It uses package `co.camilo.transmicrone`, separate from development builds ending in `.debug`. Existing debug boards do not automatically transfer to this separate installation.
